Période
Chaque ligne est un habitant : la couleur dit où il est ; le filet au-dessus marque les moments passés avec quelqu'un ; les triangles rouges sont les alertes du contrôle. Cliquer ou utiliser les flèches pour choisir l'instant (Maj : une heure).
