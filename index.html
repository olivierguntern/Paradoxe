Remontez le temps. Ne contredisez jamais votre passé.

    Règles et commandes
    • Flèches, ZQSD ou WASD : se déplacer
    • Espace : attendre un tour
    • R : remonter le temps (la boucle actuelle devient un écho)
    • Retour arrière ou U : annuler
    • N : recommencer le niveau
    • Une plaque ouvre les portes de même couleur tant que quelqu'un s'y tient.
    • Une porte rayée est inversée : elle se ferme quand sa plaque est pressée.
    • Les échos rejouent exactement vos boucles précédentes. Le petit cercle indique leur prochaine position.
    • Paradoxe si un écho ne peut plus refaire son trajet, ou si vous le rencontrez.
